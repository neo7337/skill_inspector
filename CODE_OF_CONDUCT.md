# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive; no harassment or discrimination.
Report unacceptable behavior privately to the maintainer via GitHub
(https://github.com/neo7337/skill_inspector/security/advisories/new or a direct message to @neo7337).
